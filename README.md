# Технология программирования - лабораторная 1

Вариант 7: корабли (подводная лодка, парусник, катер).

## Этап 1

Абстрактный Base, три производных класса, динамическая память для текста,
ввод/изменение полей, конструкторы и деструкторы с диагностикой,
глубокое копирование и перегрузка вывода и присваивания.
Демонстрационное меню создаёт объекты из введённых пользователем данных.
STL-контейнеры не применяются.

## Сборка

Windows, g++ (MSYS2 UCRT64), C++17: запустите `build.cmd`, затем `ships.exe`.

## Следующие этапы

В отдельный день: Keeper, полное меню, файловое сохранение и восстановление.
Ещё в отдельный день: регрессионные проверки и окончательная документация.
Даты коммитов реальные, не изменяются вручную.
