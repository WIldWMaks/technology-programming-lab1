# Технология программирования - лабораторная 1

Вариант 7: «Корабль». Base -> Submarine, Sailboat, Motorboat; Keeper владеет
динамическим массивом указателей на Base. STL-контейнеры и std::string не используются.

## Запуск

Windows + g++ (MSYS2 UCRT64), C++17: запустите build.cmd, затем ships.exe.
Все данные и имя файла вводятся с клавиатуры. Десятичный разделитель - точка или запятая.
Меню: добавление, просмотр всех/одного, изменение отдельного поля, удаление,
копирование корабля/контейнера, очистка, сохранение и восстановление.

## Формат файла

Текст UTF-8: SHIP_KEEPER_V1, количество, код типа и поля каждого объекта - по строкам.
1 - Submarine, 2 - Sailboat, 3 - Motorboat. Дробные числа сохраняются с точностью 17 знаков.
Восстановление заменяет контейнер только после проверки всего файла.
Подводная скорость, дважды повторённая в задании, хранится одним полем.

## Проверки

Собрать tests.cpp вместо main.cpp с остальными cpp-файлами; запустить
`tests.exe test.data`. Проверяются освобождение памяти, глубокие копии,
индексы, ошибки ввода, восстановление и отказ от повреждённых файлов.

## История разработки

По методичке нужны не менее трёх коммитов, разнесённых во времени.
Пользователь уточнил: три разных календарных дня.
Первый этап - иерархия кораблей; второй - Keeper и полное приложение;
третий - тесты и окончательная документация. Финальная локальная версия
может быть подготовлена заранее, но последующие коммиты выполняются
в реальные последующие дни. Даты истории не подменяются.
